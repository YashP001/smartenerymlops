# Dataset Management and Data Quality (Member 1)

This directory houses the dataset versioning, storage specifications, and retrieval workflows for the **AI-Assisted Smart Home Energy Advisor** project.

---

## 1. Dataset Overview

### Source
The project uses the Council on Energy, Environment and Water (**CEEW**) smart-meter electricity dataset for Mathura and Bareilly, India.
- **Primary Raw Dataset:** `data/raw/SM Cleaned Data MH2021.csv` (Mathura 2021 readings, 550,560 rows)
- **Aggregated Reference Dataset:** `data/raw/SM Cleaned Data MH Aggregated.csv` (daily/monthly aggregated statistics)

### Column Schema
| Column | Type | Description |
| --- | --- | --- |
| `x_Timestamp` | datetime | Timestamp for the reading (recorded at 3-minute intervals) |
| `t_kWh` | float | Electricity consumption during interval |
| `z_Avg Voltage (Volt)` | float | Average line voltage |
| `z_Avg Current (Amp)` | float | Average line current |
| `y_Freq (Hz)` | float | Grid frequency |
| `meter` | string | Smart meter identifier |

### Sampling Interval & Known Limitations
- **Nominal Sampling Interval:** 3 minutes (480 expected readings per meter per day).
- **Missing Values:** No null values present in raw CSV.
- **Timestamp Gaps:** 261 transmission drop gaps detected where delta > 3 minutes (largest gap: 29 days).
- **Domain Outliers:** Voltage spikes (>300V) and frequency anomalies (>55Hz) exist in raw data and are validated prior to modeling.

## 2. DVC Dataset Versioning Architecture

To keep the Git repository lightweight, large datasets are **not committed to Git**. Instead:
1. **DVC** tracks dataset contents, computes cryptographic hashes (MD5), and manages version pointers (`.dvc` files).
2. **Git** tracks only lightweight `.dvc` pointer files and `.gitignore`.
3. **Google Drive** serves as the remote storage backend holding the actual data payloads.

### Repository Layout
```
data/
├── README.md                                    # This documentation
├── raw/
│   ├── .gitkeep                                 # Preserves directory in git
│   ├── .gitignore                               # Autogenerated by DVC (ignores *.csv)
│   ├── SM Cleaned Data MH2021.csv               # Raw data (tracked by DVC, ignored by Git)
│   ├── SM Cleaned Data MH2021.csv.dvc           # DVC pointer file (tracked by Git)
│   ├── SM Cleaned Data MH Aggregated.csv        # Aggregated data (tracked by DVC, ignored by Git)
│   └── SM Cleaned Data MH Aggregated.csv.dvc    # DVC pointer file (tracked by Git)
└── processed/
    └── .gitkeep                                 # Target for pipeline features & splits
```

## 4. DVC Workflow and Operational Commands

### Prerequisites
Install DVC with Google Drive remote support:
```bash
pip install "dvc[gdrive]"
```

### 1. Retrieving Datasets (`dvc pull`)
To fetch the datasets on a fresh checkout or new machine:
```bash
# Pull all tracked datasets from Google Drive remote
dvc pull

# Or pull a specific dataset
dvc pull data/raw/SM\ Cleaned\ Data\ MH2021.csv.dvc
```
*Note on Authentication:* On the first push/pull, DVC will output a Google OAuth URL. Open it in a browser, sign in with authorized credentials, and copy the verification code back into the terminal.

### 2. Tracking New or Modified Datasets (`dvc add`)
Whenever a raw or processed dataset is updated:
```bash
# 1. Track the dataset with DVC
dvc add "data/raw/SM Cleaned Data MH2021.csv"
dvc add "data/raw/SM Cleaned Data MH Aggregated.csv"

# 2. Stage the pointer and gitignore files in Git
git add data/raw/*.dvc data/raw/.gitignore .dvc/config

# 3. Commit the new dataset version to Git
git commit -m "chore(dvc): update raw dataset version"
```

### 3. Pushing Datasets to Remote (`dvc push`)
To upload new dataset versions to the team's shared Google Drive remote:
```bash
# Push tracked data to Google Drive
dvc push
```

### 4. Checking Data Tracking Status (`dvc status`)
To verify whether local datasets match the recorded DVC state:
```bash
dvc status
```

## 5. Security and Credential Guidelines

- **No Secrets in Git:** Never commit OAuth tokens, credentials, service account JSON keys, or `.env` files to Git.
- **Local Cache:** Authentication tokens are kept in the local DVC cache (`.dvc/tmp/`), which is automatically ignored by `.dvc/.gitignore`.
- **Public/Private Drives:** If using a restricted team drive, ensure members have at least 'Viewer' (for pull) or 'Editor' (for push) permissions on Google Drive folder ID `1cy5HL-ElHkdoFUeD97SxjosN3ELpzpG2`.

## 6. Data Validation Pipeline

Before feeding raw data into feature engineering or training pipelines, validate data quality:

```bash
# Run validation checks on raw data
python src/data_validation.py

# Or specify a custom dataset path
python src/data_validation.py "data/raw/SM Cleaned Data MH2021.csv"
```

The validation script runs:
1. `check_missing_values`: Validates that no null values exist.
2. `check_duplicates`: Validates uniqueness on `['meter', 'x_Timestamp']`.
3. `check_timestamp_integrity`: Detects ordering anomalies and gaps > 3 minutes.
4. `check_feature_ranges`: Validates voltage (150V–300V), frequency (45Hz–55Hz), and non-negative `t_kWh`.
