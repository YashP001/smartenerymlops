# AI-Assisted Smart Home Energy Advisor

## Project Overview
This project uses machine learning to predict household
appliance energy consumption and demonstrates an MLOps workflow.

## Dataset
UCI Appliances Energy Prediction

https://archive.ics.uci.edu/dataset/374/appliances+energy+prediction

## Tools
- Python
- Git and GitHub
- DVC
- MLflow
- Scikit-learn

## Project Structure
- data/raw: original dataset
- data/processed: prepared dataset
- notebooks: data exploration
- src: reusable Python code
- tests: automated tests
- reports: findings and graphs
- models: saved model files, if required
