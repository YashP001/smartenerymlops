# AI-Assisted Smart Home Energy Advisor

## Project Overview
This project aims to predict household appliance energy consumption using machine learning and demonstrate a complete MLOps workflow.

## Dataset
The dataset is currently under consideration and has not been finalized. The dataset source, columns, license, and preparation steps will be documented after the team and faculty approve it.

## Phase 1: Development and Reproducibility
- Dataset selection and exploratory data analysis
- Data cleaning and feature engineering
- Baseline model training and evaluation
- Git and GitHub version control
- DVC data versioning
- MLflow experiment tracking

## Tools
- Python
- Git and GitHub
- DVC
- MLflow
- Jupyter Notebook
- Scikit-learn

## Project Structure
- `data/raw/`: original dataset
- `data/processed/`: processed dataset
- `notebooks/`: exploratory analysis
- `src/`: reusable Python code
- `tests/`: automated tests
- `reports/`: project reports and graphs
- `models/`: saved models, if required

## Setup
1. Clone the GitHub repository.
2. Create and activate a Python virtual environment.
3. Install the required packages from `requirements.txt`.
4. Follow the dataset download and DVC instructions once the dataset has been finalized.

## Team
This project is being developed by a team of four members. Team responsibilities are divided across project setup, data analysis, feature engineering, model development, and experiment tracking.
